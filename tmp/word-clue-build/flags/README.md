# Super Over flags

`india.svg` and `pakistan.svg` preserve the game's existing inline flag artwork.

`sri-lanka.svg` is the national flag from Wikimedia Commons, supplied locally so the game does not depend on a third-party image request. The source describes the artwork as public domain and based on SLS 1:2020.

- Source: https://commons.wikimedia.org/wiki/File:Flag_of_Sri_Lanka.svg
- Original SVG: https://upload.wikimedia.org/wikipedia/commons/1/11/Flag_of_Sri_Lanka.svg
- Vectorization credited by the source: Zscout370 and Mike Rohsopht.
